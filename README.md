# Compatibility Matrix for Android Gradle Plugin and IntelliJ IDEA

I got tired of searching for the current version of the Android Gradle Plugin (AGP) supported by IntelliJ. 

To keep track of this information until a formal [Compatibility Matrix](https://youtrack.jetbrains.com/issue/IDEA-321132/AGP-compatibility-table) is provided or until IntelliJ IDEA is enabled to work with unsupported AGP versions, I created this repository.

> [!IMPORTANT]
> The latest version will always be listed at the top.

| IntelliJ Version (Build Number) | AGP Version | [Android Plugin for IntelliJ IDEA & AppCode](https://plugins.jetbrains.com/plugin/22989-android)   |
| :------------------------------:| :---------: | :------------------------------------------------------------------------------------------------: |
| 2025.3.1 (#IU-253.29346.138)    | 8.13.x      | [Version 253.29346.138](https://plugins.jetbrains.com/plugin/22989-android/versions/stable/915697) |

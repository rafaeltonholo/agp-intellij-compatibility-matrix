# Compatibility Matrix for Android Gradle Plugin and IntelliJ IDEA

To keep track of this information until a formal [Compatibility Matrix](https://youtrack.jetbrains.com/issue/IDEA-321132/AGP-compatibility-table) is available or until IntelliJ IDEA supports unsupported AGP versions, I created this repository.
